# Source provenance

This public alpha is an allowlisted export of the private DevGap prototype at source revision `934cbe02b7cb4b444713910e1b28f546ce78eab7`, followed by release preparation.

Public Git history starts from a clean licensed baseline. Private planning documents, local paths, task receipts, model/session records, evaluations and full test applications are excluded. The original history remains preserved privately; no original repository history was rewritten or mirrored.

The original MIT notice, Copyright (c) 2026 DevGap contributors, is retained. This project does not bundle third-party runtime libraries or copy third-party skill implementations. Referenced documentation and the external skills installer keep their own licenses. The installer is optional tooling, not vendored code.
